# Claude 4.8 UltraCode AgentSwarm Environment Workspace

Global multi-agent automation workspace for uncompromised full-autonomy coding using local/cloud Ollama qwen3-coder pipelines.

## 🚀 Fresh PC Installation Instructions
1. Open Windows PowerShell and run standard dependencies:
   ```powershell
   winget install Git.Git
   winget install Python.Python.3.11
   winget install BurntSushi.ripgrep.MSVC
   pip install aider-chat
   ```
2. Right-click `install.bat` inside this repository and select **Run as Administrator** to deploy all system files and shortcut macros instantly.
3. Navigate to any project directory and launch your workspace using: `aider-cloud UltraCode`
